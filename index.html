FAQ

Windows says "Windows protected your PC"

That's SmartScreen warning about an installer that isn't code-signed. Click More info, then Run anyway.

Does it need admin rights?

No. It installs for your user only, in %LOCALAPPDATA%\Programs\FPV Sim, with a Start menu shortcut and an uninstaller in Settings → Apps.

Which controllers work?

Xbox, PlayStation and most USB / Bluetooth gamepads, RC radios that show up as a USB joystick (EdgeTX / OpenTX in joystick mode), and DJI remotes (RC-N1 / RC-N3 / FPV remote). The Controls tab has a calibration wizard.

How do I play with friends?

One of you runs a server (see the server website), shares its address, and everyone adds it in the Multiplayer tab.

Where are my settings and recordings?

In the app's own storage on your computer. Uninstalling the game doesn't delete them.
