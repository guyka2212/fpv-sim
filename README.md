# FPV Sim

FPV drone simulator for Windows and Android: 12 maps, 5 real drone classes, multiplayer, VR goggles
and a replay editor.

**Website and downloads: https://guyka2212.github.io/fpv-sim/**

- Windows: [FPV-Sim-Setup.exe](https://github.com/guyka2212/fpv-sim/releases/latest/download/FPV-Sim-Setup.exe)
- Android: [FPV-Sim.apk](https://github.com/guyka2212/fpv-sim/releases/latest/download/FPV-Sim.apk)
- Host a multiplayer server: https://guyka2212.github.io/flysim-servers/

This repository holds the website (GitHub Pages); the game itself is in the
[releases](https://github.com/guyka2212/fpv-sim/releases).
